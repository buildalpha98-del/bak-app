# Fix brief — Build Alpha Kids platform audit (2026-10-26)

You are fixing the findings in `docs/audits/2026-10-26-deep-dive.md` in this repo (`~/Developer/BAK-APP`, Next.js 14 App Router + Supabase + Vercel Sydney). ## Ground rules

1. **Work in phases, one PR per phase, branch off a fresh `main`** (`git fetch origin && git checkout -b fix/audit-p<N> origin/main`). Confirm `git remote -v` shows `buildalpha98-del/bak-app` before touching anything. Do not merge; open the PR and stop.
2. **Never bypass the project's single sources of truth.** `setSessionCoaches` is the only coach write path; `priceShiftForCoach` the only pricing rule; `lib/sessions/coach-membership.ts` the only "is coach on session" check; `lib/staff/coach-pool.ts` the only coach-pool filter; `lib/ai/model.ts` the only model id; `components/ui/app-link.tsx` the only Link. The CI guard tests under `lib/__tests__/` will fail the build if you do otherwise — do not weaken them.
3. **Migrations:** new files in `supabase/migrations/` numbered from `103_`, one concern per file, idempotent (`DROP POLICY IF EXISTS` before `CREATE POLICY`, `CREATE INDEX IF NOT EXISTS`). Every policy you add or change gets a comment naming the audit section. Do **not** apply migrations to any database — Jayden applies them. Write the migration and the app change in the same PR.
4. **Verify at the seam, not with mocks.** Every serious bug in this codebase passed a green unit suite. For each fix: add or extend a test that would have failed before the fix. For RLS/auth fixes that means an e2e spec in `e2e/` following the self-provisioning pattern in `e2e/second-coach.spec.ts` / `e2e/teacher-seam.spec.ts` (throwaway users, delete in `finally`, read-only otherwise). Do not run `npm run e2e` yourself unless `.env.production.local` is present and Jayden has said to; write the spec so it is ready to run.
5. **Dates:** use `lib/utils/sydney-time.ts` helpers only (`sydneyTodayIso`, `addDaysIso`, `daysBetweenIso`, `sydneyIsoDateTime`, `SYDNEY_TZ`). Add a `mondayOf(iso)` there (string-walking, no `Date` getters) and delete the copies. Never `new Date().toISOString().split("T")`, never `toLocale*` without `timeZone: SYDNEY_TZ`, never relative time during render (use `<TimeAgo>`).
6. **Errors:** destructure `error` from every Supabase call you touch and throw or return it; never `data ?? []` over an unchecked error. No new `console.*` — if the file already has them, leave them, but do not add more. Never catch-all around code that may call `redirect()` / `notFound()`.
7. **Before claiming a phase done:** `npx tsc --noEmit`, `npx vitest run`, `npm run build` all pass; the PR description lists each audit section number fixed, each not fixed and why, and the exact command or query that proves each fix. Report test output faithfully.
8. Do not touch `scripts/.rehearsal-*`, `e2e/smoke.spec.ts`, Vercel settings, or any `.env*` file. Do not rotate or print secrets.
